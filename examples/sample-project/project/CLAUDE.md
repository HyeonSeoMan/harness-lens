# todo-api (합성 샘플)

> 합성 샘플이다. 실제 서비스·사람·조직과 관계없다.

할 일 목록을 다루는 작은 HTTP API다. TypeScript + Node.js, 패키지 매니저는 npm.

## 완료 정의

- 변경마다 요구사항과 수용 기준을 PR 설명에 적는다.
- `scripts/verify.sh`(타입 검사·린트·테스트)가 통과해야 완료로 본다.

## 작업 규칙

- 공개 API(`src/routes.ts`)를 바꾸면 테스트를 함께 고친다.
- 릴리스 전에는 release-check Skill로 변경 기록과 버전을 확인한다.
- 같은 명령이 실패하면 원인을 적고 세 번 넘게 재시도하지 않는다.

## 금지

- `.env` 파일과 비밀 값을 읽거나 커밋하지 않는다.
- main 브랜치에 force push 하지 않는다.
