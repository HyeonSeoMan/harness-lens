## N8 원인 조사와 결정

원본 세션 대화는 열지 않고 기존 결과의 `sessions/cursor.json` 숫자 집계와 2회차 `analysis.json`만 읽었다. 구성 시작 `2026-11-27T11:10:06Z` 이후 귀속된 프로젝트·워커 메인 세션 28개를 동일 조건으로 재구성했다.

- 19개: 도구 호출 0, 사람 입력 1, assistant 기록 1, 첫~마지막 관측 1,163–1,525ms.
- 나머지 9개: 도구 호출 7–63개, 관측 시간 43,975–813,360ms.
- 기존 중앙 1,416ms는 실제로 도구 작업 없는 19개 때문에 낮아졌다. 이 세션들이 사용자의 관점에서 빈 대화인지, 단순한 요청이었는지는 숫자만으로 단정하지 않는다.

처리 속도는 작업 수행을 보는 지표이므로 메인 도구 호출이 관측된 세션만 표본과 소요 시간 집계에 쓴다. 임의 시간 하한은 두지 않아 짧아도 도구 작업이 있으면 포함한다. 자율성의 입력 간 도구 호출·사람 입력 평균도 같은 작업 세션을 쓰되, 성숙도 요구량은 기존 **메인 도구 호출 500회**를 유지한다. 전체 토큰·귀속 세션 수와 컨텍스트 지표 표본은 바꾸지 않는다.

수정 후 동일 실제 기록의 처리 속도 표본은 9/20(45%), 세션 관측 시간 중앙은 152,637ms, 입력 사이 도구 호출 중앙은 14(표본 9)다. `turn_duration` 기록은 여전히 없으므로 세션 관측 시간을 실제 턴 소요 시간으로 대체하지 않는다. 자율성 표본은 기존과 같은 도구 호출 195/500이며 예측 상태다.

## 실제 자료 검증

`~/Documents/DiceForge`는 읽기만 했다. 기존 결과도 수정하지 않고 config·latest·snapshots·숫자 세션 상태를 임시 결과 디렉터리에 복사했다. 새 번들의 `prepare --scope project --out <임시 결과> --now 2026-11-28T15:00:00Z`로 실제 대상과 실제 세션을 함께 읽었다.

- 보존된 2회차 초안에 새 압축기만 적용: 6,673 → **5,840토큰**.
- 엔진 0.4.1로 실제 prepare 재실행: `sessionsStatus: available`, **5,387토큰**. 상한 6,000 이내다.
- 대상 밖 cwd에서 실행한 직전 분석은 `llmTokens: null`·`method: unknown`이며, 제외 원인을 `analysis_tokens_unmeasured`와 리포트에 명시한다. 귀속된 봇의 측정은 합성 기록 회귀 테스트로 확인한다.

실제 기록·경로별 목록·토큰 원본은 저장소에 넣지 않았다. 회귀 테스트는 합성 기록으로 수집기 버전 비교, 귀속 봇·대상 밖 cwd, 19개 비작업 세션 제외, 컨텍스트 표본 보존, 압축 마지막 단계의 초과 거부, 비교 불가 레이더, 실측 차단 사유, JSON 위치 안내를 검증한다.
